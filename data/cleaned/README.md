# Cleaned Data Directory

This directory contains cleaned and preprocessed data generated by `scripts/02_transform.py`.

## Contents

After running the transformation script, this directory will contain:
- `coffee_sales_cleaned_YYYYMMDD.csv` - Cleaned data in CSV format
- `coffee_sales_cleaned_YYYYMMDD.parquet` - Cleaned data in Parquet format (recommended)

## Data Cleaning Steps

The transformation script performs:
1. Duplicate removal
2. Missing value handling
3. Date/time parsing
4. Feature engineering (time-based features)
5. Data type validation

## Usage

Load the cleaned data for analysis:

```python
import pandas as pd

# Load from Parquet (faster)
df = pd.read_parquet('data/cleaned/coffee_sales_cleaned_YYYYMMDD.parquet')

# Or load from CSV
df = pd.read_csv('data/cleaned/coffee_sales_cleaned_YYYYMMDD.csv')
```

## Note

Cleaned data files are excluded from git to keep the repository size manageable.
